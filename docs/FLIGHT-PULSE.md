# 分层航行与脉冲光束

2026-11-06。此记录覆盖整套战斗整合后的背景、武器表现与事件修复。当前包体身份以 `build-info.json` 为准。

## 空间与衔接

三个章节分别使用 image-2 原创远景：碎星废舰轨道、靛蓝风暴、母舰装甲深域。远景只做极轻微横向视差，没有纵向平铺、镜像或重复拼接。六件透明景物按章节分组，最多四件同时存在，从中央战斗区以外的两侧单次经过并离场；最多十二条低亮度、亚像素宽的短星尘提供近景速度感，精简档六条，减少动态模式隐藏星尘。

章节切换持续四秒：旧远景与新远景用smoothstep混合，旧景物沿原方向移动并淡出，新景物延后进入并淡入。暂停、选卡和事件窗口冻结航行时钟，结算后停止。素材源图与制作说明在 `assets/art-direction/flight-v2/`。

## 脉冲光束

每周期0.7秒：0–0.12秒聚能、0.12–0.20秒爆发、0.20–0.58秒持续输出、0.58–0.70秒收束。光束以世界尺寸绘制，避免继承机体0.6倍缩放；无阻挡时伸出视野顶部，穿透最多三个目标，在第三个接触处显示撞击终点。光束核心、能量鞘和流动细丝由着色器产生，接触点最多三个。

实际伤害沿用原弹体的命中/元素/独立改造流程，有效输出阶段按占空比积累结算额度。基础7秒样本造成84点伤害，旧理论基准约86.15，误差约2.5%；这不是所有构筑均衡的保证。升级增加束体、炮口和细丝表现；精简档保留核心和接触点，减少能量纹理，不改变伤害。

专属音效由 `tools/gen_beam_audio.py` 合成：三条0.7秒的聚能/爆发/持续/衰减组合音与一条接触音。独立播放器避免自动射击音池截断持续声，接触声限频0.14秒。暂停冻结播放，换武器、死亡和结算停止声音。网页仍需浏览器允许用户手势后的音频播放。

## 验证

- `flight_pulse_test.gd`：22项条件，包括120秒景物数量边界、章节中点、三目标穿透、可视终点、有效阶段伤害、射程、音效状态与暂停/死亡清理。
- `campaign_ui_test.gd`：真实55秒补给事件、鼠标接受/绕行、视口缩放与暂停同步；先前右下角越界和暂停后按钮失效均有回归覆盖。
- 构筑72项、机型33项、新增战斗92项、反应81项、特效169项、敌舰76项，以及完整冒烟流程。
- `flight_pulse_web.cjs`：真实Chrome WebGL/WebAudio、1152×648及844×390/4倍CPU降速；确认用户手势后音频上下文running、光束周期推进和无页面错误。

首轮并行验证曾记录明显低帧样本，保留原报告后再次单独测量；不能据此宣称首次出现所有特效均无编译卡顿。桌面GPU配合CPU限速不代表实体手机。最终混音的耳机/扬声器试听、真机发热和留存仍需人工验证。部分无头退出有既有ObjectDB/资源引用警告。

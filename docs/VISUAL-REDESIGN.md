# No Survivor 视觉改版首版

此文记录首轮实现；后续敌舰、弹体、血条与模块翻牌改版见 VISUAL-V2.md。

日期：2026-10-28。基于 main 的独立本地分支 `codex/visual-overhaul`。

## 项目理解与范围

Godot 4.7 / GL Compatibility 真3D弹幕游戏，战斗在XY平面，镜头从+Z观察。自动射击、鼠标/触屏移动、元素与弹道强化、Boss核心变形、20形态、6类敌机和6类Boss均已有实现。

此次仅替换视觉表现。场景、碰撞、player/enemy/boss数值与行为、刷怪、强化、存档及变形时序的原文件均未改动。world.gd 仅替换UI字体并调用视觉皮肤；project.godot 仅替换默认字体。原 Quaternius CC0 资源及许可证保留，方便比较与回退。

## 美术方向

主角：珍珠白装甲、深色结构、青色座舱与推进口、少量琥珀警示；三角机身与分层翼片保证原生战斗尺寸下可辨识。形态推进增加前翼、武器支架、附加引擎、外翼与反应核心，后十形态有新增几何结构，不只换色。

小怪：酒红装甲、金属骨架，六个职责对应矛形、细针、侧翼、双炮、前盾与重甲。原有角色光色保留在核心与识别灯上。

Boss：红色四炮毁灭者、紫色分叉拦截者、绿色六边装甲要塞、琥珀长轨猎手、冰蓝侧翼幻影、环形OMEGA母舰；增加分块装甲、凹槽、炮塔底座与反应核心。它们保持原有归一化尺寸与朝向，不修改碰撞盒。

界面：深海军蓝舰载终端，细线边框、青色主操作、金色焦点、少量角色警示色。标题、说明和交互使用原生文字与按钮，避免把可点击区域和中文烘焙到图片里。开场使用原创机库主视觉，其余弹层保持安静背景，保留战场上下文。

## 实现

- `scripts/visual_fleet.gd`：生成真实分层三角网格，不是平面精灵替代3D。每舰按六种材质合批，几何缓存为PackedScene；主角呼吸灯材质独立，实例间不互相污染。
- `scripts/model_builder.gd`：保留原工厂入口及尺寸配置，仅将主角/敌机/Boss接到新舰体。
- `scripts/visual_ui.gd`：给既有控件应用Theme与装饰，保留原信号、按钮功能及页面流程。包含开场、HUD、强化、暂停、失败、胜利。
- `assets/hangar.webp`：实际使用的机库图，1920px宽、WebP质量88。
- `assets/fonts/NoSurvivorUI.ttf`：Noto Sans SC的500字重本地子集，271236字节，覆盖当前项目源文案和ASCII。保留SIL OFL许可，修改后的字体族名为No Survivor UI。
- `tools/subset_ui_font.py`：可复现子集生成。原字体来源是 Google Fonts 的 `ofl/notosanssc/NotoSansSC[wght].ttf`，原版许可在 `assets/fonts/NotoSansSC-OFL.txt`。新增动态文案时需重新生成子集。
- 导出排除概念原图、验证工具、截图和本地工具环境，避免把制作资料带给玩家。

## 图像生成来源

内置image_gen完成主角谱系概念、Boss舰队概念与机库背景；模型ID未由工具暴露。原图、用途与完整提示词在 `assets/art-direction/provenance.json`。所有三维舰体依概念重新构建实际几何，概念图不等于已生成的网格；目前是适合原生战斗尺度的风格化几何实现，非概念渲染的逐像素复刻。

## 验证

- Godot原有smoke_test：35项开局、刷怪、强化、暂停、元素/弹道、变形、Boss、OMEGA、胜利、无尽、追踪导弹、复活和阵亡检查通过。
- visual_test：20种主角形态几何签名均不同；6种小怪、6种Boss都可实例化；归一化尺寸及敌机朝向保持原配置；主角发光材质独立。
- 在RTX3060 / OpenGL兼容渲染实际采集机库、战斗、强化、暂停、结算、舰队图，检查了原生战斗尺度和全舰队轮廓。capture_visuals使用受控场景、测试生命和直接触发流程，属于视觉展示，不代表人工通关。
- Godot Web Release导出成功；Chrome中实际加载、点击开始、战斗、Esc暂停，并查看1152×648及844×390横屏。最终浏览器检查未见资源错误、未捕获错误或脚本错误，结果在 tools/visual-web-check.json。
- 已对比原始HEAD，场景、碰撞和核心玩法文件未变。

本地启动：`node tools/serve_preview.cjs`，入口 http://127.0.0.1:8316/ 。需要预先使用已有Web导出预设生成 build/web/index.html。

## 边界

尚未推送GitHub、部署Pages或发布平台。未做真实手机GPU性能与触控验收；浏览器横屏截图不是手机实测。新舰体每种有六个材质批次，移动端大规模同屏性能仍需测量。原有无头smoke在退出时仍报告BGM.wav/播放实例引用，详细日志定位为音频退出清理；本轮未改动原音频逻辑。完整三维雕刻、法线烘焙和DCC机械绑定不在此首版实现中。

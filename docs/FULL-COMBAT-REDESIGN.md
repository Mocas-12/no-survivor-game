# 整套战斗改造 · 整合记录

开发日期：2026-11-06。预览入口：`http://127.0.0.1:8318/?v=flight-pulse`。

本文件描述实际实现，不把概念图、受控截图或无敌机器人通关解释为真人体验或真机表现。当前发布以 README 与 build-info.json 为准；后续飞行背景和脉冲光束改造见 FLIGHT-PULSE.md。

## 构筑与成长

- 三种开局机型：突击型持续接战积累过载；护航型使用导弹和随移动展开的辅助阵位；攻坚型使用贯穿轨道炮及周期重炮。三次关键进化保留机型，进入5/10/15舰体阶段；选项过滤已有专精，说明改造的装配和替换目标。
- 六类主武器有独立实体弹体：脉冲、轨道、导弹、回旋刃、持续光束、部署式感应雷。光束按周期结算最多三个对齐目标，感应雷部署后等待附近敌人。主炮与两个辅助槽分别保留两个改造，切换武器不会丢失原有装配。
- 48张模块保留原有基础成长，新增25张模块使用各自插画。玩家可以选择装配槽、查看满槽替换目标，每局三次重抽并可跳过。触屏事件覆盖装备槽、跳过、重抽及委托按钮。
- 元素来自主炮、两辅助及改造弹芯。蒸汽回收核心留下两秒残留场，碎裂可配合分裂模块传播冰标记。副伤害与衍生弹不递归触发同一条生成链，目标触发冷却使用游戏时间。蒸汽场同时最多四个，主炮活跃弹数有预算保护。
- 结算火力贡献按目标剩余生命限制记录，区分武器、辅助、衍生攻击与元素反应；显示完成委托数和实际出现的反应类型数。

## 三幕战役与敌人

三幕分别为碎星巡航、风暴防线、母舰深域；背景在击破本幕Boss后切换，中央留有较暗的战斗区。

保留12组遭遇，六类新职责逐步加入：维修、布雷、护盾投射、分裂、牵引、侧袭轰炸。三个场景各有风险委托，可自由绕行；接受后在45秒内完成击破目标才获得威力与修复奖励，失败保留已收集收益。奖励只发一次。

每局两只打乱选择的普通Boss加终局OMEGA。首Boss在150秒进入，后续间隔调整到240秒，为中后期构筑留出使用空间。所有Boss保留各自P2攻击与移动变化，OMEGA具有P3；转换约两秒，清理旧敌弹并逐步展开实际机械分组。

## 验证入口与边界

- `tools/full_plan_test.gd`：72项，覆盖独立改造、真实元素联动、奖励防重、触屏操作、场地上限、持续光束、新模型、低档特效及弹池休眠。
- `tools/final_hostile_test.gd`：76项，检查19个模型的预算、体积、可动分组及法线贴图。
- 既有构筑33项、新增构筑92项、战斗反应81项、特效169项作为回归。
- `tools/full_campaign_test.gd`：三机型完整无敌参照和正常承伤驾驶；结果包含是否通关、时长、击破、承伤、等级与场上数量。自动驾驶不代表真人通关率，参照轮明确标注无敌。
- `tools/full_plan_web.cjs`：真实Chrome加载、选卡、密集场景，1152×648与844×390横屏、4倍CPU降速。性能报告记录GPU与样本；桌面GPU加CPU降速不等于实体低端手机。
- `tools/smoke_test.tscn`：开局、升级、暂停、进化、Boss各阶段、胜利、复活与失败流程。

浏览器可拒绝全屏与方向锁定；页面处理失败后继续内嵌运行，不放宽浏览器权限。

最终本地检查：六组测试合计523项通过，完整冒烟流程通过，Web导出成功。Chrome最终采样没有页面错误：1152×648平均141.1帧、最低136帧；844×390、4倍CPU降速平均31.1帧、最低24帧。样本来自RTX 3060桌面环境，不能作为手机稳定30帧的证明。

触屏默认使用精简特效；持续低于40帧两秒也会自动切换。精简档去除逐弹CPU拖尾，限制次要粒子与并发效果，保留实体弹体、主要反应和Boss阶段变化，不修改伤害、敌人数与碰撞体。休眠弹池关闭逐帧回调，再发射时恢复。

六轮完整战役审计中，无敌参照的突击、护航、攻坚分别在699.0、699.4、739.7游戏秒通关；正常承伤机器人只有护航通关，突击和攻坚分别在137.2、17.0秒阵亡。这些结果明确表明自动驾驶对直射机型不利，且机型平衡仍有风险，不能用三次无敌通关宣称难度均衡。测试采用8倍速与固定驾驶策略，也不替代正常速度的真人试玩。

部分原有Godot测试退出仍报告静态资源/ObjectDB残留，不能据此宣称零退出警告。实体手机的帧率、热量与完整手感仍需真机复核；留存提升也需要真实试玩数据。

## 本地运行

### 首轮补给窗口与飞行背景修复（背景方案已被 FLIGHT-PULSE.md 替代）

修复事件窗口的居中锚点叠加绝对偏移导致右下角越界，以及暂停战斗时原生按钮不再处理鼠标的问题。事件窗口由铺满视口的CenterContainer居中，按钮在暂停时仍可处理输入；接受和绕行均解除暂停。`tools/campaign_ui_test.gd`先复现四个失败断言，再验证真实55秒事件、鼠标接受/绕行、视口缩放及背景暂停。

三幕背景改为慢速滚动，叠加不同速度的远近星尘与横向驾驶视差；使用游戏驱动时间，暂停与结算时停止，不使用不受暂停控制的全局着色器时间。原有图片采用镜像边界延展，避免普通平铺的硬接缝。复用现有星空素材，无新增外部资源。

Godot 4.7直接打开 `project.godot`。已有Web导出位于 `build/expansion/`；运行 `node tools/serve_expansion.cjs` 可启动无缓存本机服务。`build/full-plan-web-report.json`、`build/full-campaign-results.json` 及构建哈希文件用于本次验证。

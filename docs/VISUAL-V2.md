# 第二轮视觉改版：敌舰、弹体、血条与模块翻牌

2026-10-28。本地分支 codex/visual-overhaul。试玩入口：http://127.0.0.1:8316/?v=visual2 。未推送GitHub或替换Pages线上版本。

## 已完成

六类小怪使用独立结构与主色：红色蝠翼、橙色细针、黄绿三翼、蓝灰炮艇、银白盾甲、紫黑攻城块体。六类Boss分别为横向炮台、分叉刃舰、悬浮六瓣要塞、不对称轨道猎舰、透明弯月幻影与环形母舰。主角20形态保持上一轮设计。

舰体由实际三角网格和几何装配构成，使用原创金属分块材质及mipmap缩小过滤。炮台后坐和喷口闪光由原有发弹事件驱动；要塞六块装甲以完整组件旋转；猎手按原有开火冷却显示充能；幻影翼片透明度轻微变化；母舰双层部件反转，并读取原有狂暴/第三阶段改变转速和展开。减少闪光模式停用新连续动态。

玩家普通、火、水、冰、雷、风及追踪转换分别有不同弹体；六种敌方来源有专属弹形。敌弹以半径8的细轮廓提示原有危险核心。拖尾收短，粒子数量减少。沿原方向旋转的是Mesh，不改变根节点运动、弹道或碰撞体。

血条改为原生Canvas仪表：玩家装甲图标、当前/最大值、连续填充与参考刻度；Boss编号徽记、名称、专属色、百分比、阶段标记和延迟扣血残影。普通Boss标记50%，OMEGA为70%/35%，与原有阶段规则一致。它们只读取原ProgressBar和Boss状态，通过信号刷新，不创建第二套生命数据。

翻卡页使用机械封装卡背与20张模块插画，三类边框表示元素、武装、机体系统，不表示稀有度。约0.7秒自动依次揭示；点击封装卡或按空格/回车可快速揭示。原生按钮保留键盘焦点和选择信号；触摸路径兼容项目禁用触摸转鼠标的设置。选中后放大、淡出其他卡，模块图像汇入战机，再调用原升级应用方法。

卡面分离类型、模块名称、效果短句和实际属性预览。基础间隔、伤害、暴击率、弹道数、装甲等显示当前→下一值；元素与波浪读取已持有等级；切换明确显示原项→目标项；复活/维修标为补充或即刻生效，不伪装成稀有度升级。数值预览不调用apply，不修改任何战斗属性。

## 美术与源码

- 原图及完整提示词：assets/art-direction/v2/provenance.json、revisions.json。工具为内置image_gen，未暴露可核验模型ID。
- 运行素材：assets/modules/ 的20张插画与1张卡背，共650764字节；assets/armor.webp 为1024×1024，200724字节。原图不进入运行包。
- tools/prepare_modules.cjs：记录裁切框、单图替换、去留白、尺寸与压缩。原图集的三处裁切问题通过单独生成完整模块修正；磁力卡去掉邻格残片。
- scripts/enemy_shapes.gd、fleet_motion.gd、projectile_geometry.gd：独立舰体、视觉动态与缓存弹体。
- scripts/combat_hud.gd：血条绘制与原有生命信号连接。
- scripts/module_card.gd、module_cards.gd、module_readout.gd：卡面、揭示/选择状态与只读属性预览。

## 验证结果

- 原smoke流程35项通过，覆盖开局、刷怪、升级、暂停、变形、Boss与OMEGA、胜利、无尽、追踪、复活和阵亡。测试仅增加等待新选择动画的步骤，原断言保留。
- visual_v2_test.gd的75项检查通过：缓存后Boss编号、独立部件、敌弹几何、20种插画、只读数值预览、实际触摸揭示、不误选、连续升级、双击只生效一次、隐藏页面取消过期回调、弹体复用与追踪转换、原碰撞半径。
- visual_test.gd继续验证20种主角几何、原归一化尺寸和发光材质隔离。
- check_visual_scope.cjs以固定原始提交为基准，确认移动、敌机行为、刷怪、强化定义、存档和碰撞场景未变；Boss移动/受伤/阶段公式以及选中后的升级应用主体未变。
- Chrome对导出包进行了真实游玩：点击开战，战斗与拾取经验实际触发卡页，鼠标选择后恢复战斗，再打开暂停。无资源、脚本或未捕获页面错误；记录在tools/visual-v2-web-check.json。未注入经验或胜负标记。
- 已检查1152×648和844×390横屏卡页截图。RTX3060/OpenGL实机采集了卡页、血条、敌舰与弹体总览；弹体总览为4倍展示尺寸。通用capture工具为受控展示场景，会设置测试生命值；浏览器visual-v2-web截图来自正常游玩，两者分开记录。

## 当前边界

尚未进行实体手机触控、低端GPU帧时间和扬声器检查。原有无头smoke退出时仍有BGM播放资源引用提示，未改原音频清理逻辑。舰体是适合原生战斗尺度的风格化3D几何，并非高模雕刻或图片到网格的自动转换。原有波浪弹道分支使用自己的弹速系数，本轮不更改其战斗行为；弹速卡展示的是基础倍率属性。

这轮不增加卡池、稀有度、收费揭牌、广告或任何战斗数值。最初的本地视觉源码备份保存在忽略目录.visual-backup-v1；原仓库资源和CC0许可证也保留。

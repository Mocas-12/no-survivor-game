# Boss 暴走、元素反应与打击反馈（本地开发版）

本轮改动在 `codex/run-variety` 本地分支。没有推送 GitHub，也没有更新 Pages。

## 可试玩内容

- 普通五种 Boss 在 50% 血量进入 P2；OMEGA 在 70% / 35% 进入 P2 / P3。七份展开形态 GLB 从已有 Blender 舰体派生，保留原 UV、法线和 AO；展开结构及 OMEGA 核心炮为实际几何。形态切换有 0.85 秒新攻击间隔，不增加生命，也不冻结玩家输入。大额伤害跨过两个阈值时依次切换；致死伤害不会触发变身。
- 删除旧狂暴光球及附加绕机装饰。双肩齐射、双刃交叉、堡垒换向螺旋、猎手轨道齐射、幻影翼尖火力、OMEGA 带安全扇区的环形炮组各有区别。幻影瞬移提前蓄光，落点位于上方战区，落地后保留开火间隔。
- 敌机长瞄准线和冲刺线全部移除。炮艇/重甲机仍在开火前 0.65 秒锁定方向，最后 0.35 秒显示局部炮口蓄光；射击有舰体后坐。锁定后不追着玩家修改弹道。
- 命中采用局部暖白闪光、轻微受击倾斜、方向性火花及新合成的轻/重金属音效。普通音效以 45ms 合并，反应震动以 220ms 合并。没有全局命中停顿。受击动画独立于碰撞体。

## 元素规则

状态和通用技能减速分开记录。每次命中最多一种反应；目标反应冷却为小怪 0.55 秒、Boss 0.8 秒。反应消耗配对标记，二次伤害不再递归挂元素。致命主弹先结算已准备的反应，再结算主弹伤害。

| 组合（双向） | 效果 | 视觉 |
|---|---|---|
| 火 + 水 | 热冲击，邻近伤害，1.8秒易伤 | 双向蒸汽喷流 |
| 火 + 冰 | 单体融化重击 | 暖色碎晶与核心闪光 |
| 水 + 雷 | 感电，优先连到浸润目标 | 分支电弧与实际目标间连接 |
| 水 + 冰 | 冻结 | 聚拢冰晶 |
| 冰 + 雷 | 碎裂，溅射 | 向外飞散的冰晶 |
| 火 + 雷 | 超载，溅射与短暂打断小怪开火 | 暖色爆核与放射电弧 |

火留下低频持续伤害，冰提供独立减速，水小幅击退，雷保留有冷却的基础连锁；风将已有状态传播给最多三个邻近目标并轻微聚拢，不直接递归触发反应。多个减速取较强值。Boss 冻结转为短暂减速及开火延后，不硬定身。反应视觉同时最多14组，低特效最多6组，每组0.58秒自动回收。

## 本地验证与源文件

- `tools/combat_revision_test.gd`：81项专项检查，包括12种有序元素配对、冷却、通用减速隔离、风传播、致命命中、六种 P2 实弹、OMEGA P3、Boss 抗性和特效回收。
- `tools/run_design_test.gd`：33项原有玩法检查；`tools/blender_hostiles_test.gd`：116项原有敌舰检查；`tools/blender_fleet_test.gd`：1818项主角配置检查。
- `tools/combat_revision_web.cjs`：真实 Chrome 操作导出 WebGL 游戏，13个 Boss 阶段、6个反应预览、开局及暂停。结果保存在 `tools/combat-revision-web-check.json`。
- `screenshots/boss-phase-comparison.png` 为相同展示尺寸的阶段对照。`boss-p2-combat.png` / `boss-p3-combat.png` 使用真实角色的受控战斗布置，不是自然通关录像。
- `tools/build_boss_phases.py` 重建七个展开形态；`assets/art-direction/hostiles-blender/boss-*-p*/` 保存可编辑 Blender 文件。运行时文件在 `assets/ships/blender-hostiles/`。`tools/gen_impact_sounds.py` 重建两份原创 PCM 音效。

试玩：`http://127.0.0.1:8316/?v=combat-rework`。机库：`http://127.0.0.1:8316/?review=fleet&v=combat-rework`，选择 Boss 后可切换 P1/P2，OMEGA 可切 P3；特效台循环播放六种实际反应几何。

当前 Web PCK 约62MB（十进制），未做实体手机帧率、内存或完整通关平衡验证；最终难度与表现仍需玩家试玩反馈。旧原型对比入口保持可用。

# 抢装构筑与开局节奏

开发验证：2026-11-08；发布整理：2026-11-10。源码与网页包一同提交，在线入口为 https://mocas-12.github.io/no-survivor-game/?v=salvage-20261110 。实际部署以在线 `build-info.json` 的源码哈希为准，Pages反映可能晚于源码合并。本地导出可通过 `tools/serve_expansion.cjs` 在8318端口试玩。

## 已实现

- 主炮两个元素槽：第二元素随每发主弹参与反应；选择第三种元素前可切换替换主元素或催化元素。元素等级分别保留，副炮继续独立工作。实体弹体带第二元素色标，光束带双色边缘。
- 五元素十种对称反应：蒸汽、热裂、冻结、感电、碎晶、超载以及火风传播、水风聚拢、冰风霜刃、雷风电弧。副伤害不递归应用元素，目标冷却和影响数量保留上限。
- 六类敌舰武装：重炮、雷仓、反射装甲、牵引、尾翼轰炸、复制弹仓。首艘运输舰在24秒起的机会窗口进入玩家前方，低耐久，首件掉落自动接近玩家；后续掉落需要主动靠近。最多三个掉落、20秒寿命。
- 两个抢装槽，回收界面提供两个改装方向和拆解充能。满槽明确显示替换目标；重复部件转为能量与维修。实际炮管/护盾/弹仓网格从敌舰拆取，安装在机翼并有发射回弹。
- 一个主动爆发按钮：空格、鼠标或右侧触摸释放，100能量、4秒持续。主武器与已装部件提供超频、重炮、光束、反射、雷场引爆、牵引和轰炸方案，可切换下次方案，当前爆发使用启动时的快照。Boss追猎充能并入爆发。
- 六种规则改造，最多两个同时生效：返航回收、反应跳跃、破盾复制、移动侧射、连续命中重击、擦弹充能。第三种明确替换最早规则，避免每局最终装齐全部规则。光束的回收规则按命中后的脉冲收束回能。
- 五种战场机会按袋抽取：运输舰、维修链、炮台、押运队、突破口。炮台被夺取后提供六秒真实支援；突破口短时推开一侧轻型敌人。核心战斗中展示实体机会，回收后才暂停选择。
- 初始主炮间隔0.18秒；攻坚起始保留连续机炮与周期重炮。前15秒轻型敌人，前55秒不随机堆厚盾/重装，之后逐步加入射击威胁。前90秒快速编队，后期在可见敌人不足时补充安静编队；非Boss活跃敌人上限22/30，Boss阶段10。
- 首次选卡12秒后允许，随后至少23秒战斗间隔。开局选项直接增强主炮，后续按强化、联动和转型方向组织。首Boss120秒，文字委托135秒后；连杀短暂停顿后逐级衰减。
- 背景保留纯薄雾远景，用有厚度、统一照明的空间站模块作为中景。远景在立体结构之后，四秒章节渐变，有限短星尘，所有时钟随暂停。

## 命中与预算

定点测试复现了旧式端点移动在大步长下跳过敌人。现在主弹单步超过20单位时检查整段路径，最多检查八个接触，保留贯穿预算与单目标去重。该修复同时降低掉帧时漏弹风险；它也使加速机器人与正常速度的比较更可信。

主炮、辅助、分裂、抢装各入口遵守活跃弹量预算；感应雷最多16枚，反应场最多4个。背景景物最多4组，减少动态模式隐藏星尘。渲染特效不拥有伤害结算。

## 验证入口

- `tools/salvage_run_test.gd`：双元素真实命中、十种反应、规则安装与替换、返航、擦弹、破盾、侧射、反射、雷场、炮台、突破口、抢装输入、暂停和旧/新快速弹道对照。
- `tools/salvage_campaign_test.gd`：三种不同偏好构筑的完整无敌参照，加三种正常承伤开局（180游戏秒上限）；记录首件时间、前90秒击破、实际装备、规则和爆发。使用16倍时间、120Hz物理；这不是正常速度真人胜率。
- `tools/salvage_web.cjs`：Chrome实际鼠标和触屏选择部件、点击爆发、WebAudio和密集场景。输入按等比例游戏区换算，包含横屏黑边。
- 既有机型、改造、反应、特效、敌舰及完整冒烟流程继续回归。

首轮机器人发现了首件装备过晚和高速漏碰撞，保留调整前报告；最终记录见本机 `build/salvage-campaign-results.json` 与 `build/salvage-web-report.json`。截图为真实引擎的受控演示。

仍需真人连续试玩判断乐趣、强度与留存；桌面GPU加CPU限速不代表实体手机。部分无头退出有既有ObjectDB/资源引用提示，个别瞬时创建/销毁网格测试有dummy renderer材质提示，网页/实际渲染检查另行记录。

## 本轮检查结果

2026-11-08最终回归：可计数的八套检查共632项通过，另有委托界面检查与完整冒烟流程通过。三条无敌参照构筑完成约11分钟整局；三条正常承伤机器人开局均达到180游戏秒测试上限，首件武装约25秒获得。加速机器人仅验证流程与组合，不代表真人胜率。

网页测试使用独立Chrome、桌面鼠标和横屏触摸仿真，验证选装、爆发、双元素与WebAudio。手机仿真压力场景存在明显帧率波动，低画质已隐藏背景次要装饰，但尚未完成实体手机性能验收。发布版保留这些验证边界；汇总记录见 `salvage-validation.json`。
